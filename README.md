# Bitrix24 VKVV4 BI Report

Прототип дашборда для работы с BI-отчётами через платформу Вайбкод.

## Запуск

1. Вставьте ключ в `.env`:

```env
VIBECODE_API_KEY=vibe_api_xxx
VIBECODE_APP_KEY=vibe_app_xxx
```

2. Запустите локальный сервер:

```bash
npm run dev
```

3. Откройте:

```text
http://localhost:5174
```

## Что уже есть

- серверный `.env`, чтобы не светить ключ в браузере;
- проверка подключения к платформе через `GET /v1/me`;
- простой экран будущего BI-дашборда;
- заготовки под список отчётов, визуализацию и AI-команды.
- локальный OAuth-вход через ключ приложения и временную серверную сессию.

## Следующий шаг

После вставки ключей выполните вход через кнопку «Войти в Битрикс24». Это создаст временную пользовательскую сессию на сервере, нужную для чтения данных портала ключом `vibe_app_...`.
