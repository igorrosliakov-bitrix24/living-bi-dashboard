# Bitrix24 VKVV4 BI Report

Встроенный дашборд Битрикс24 с визуальным и AI-редактированием настроек через платформу Вайбкод.

## Запуск

1. Вставьте ключ в `.env`:

```env
VIBECODE_API_KEY=vibe_api_xxx # только локальная разработка и деплой
VIBE_APP_KEY=vibe_app_xxx     # ключ приложения для работы внутри Битрикс24
```

2. Запустите локальный сервер:

```bash
npm run dev
```

3. Откройте:

```text
http://localhost:5174
```

## Что уже есть

- серверный `.env`, чтобы не светить ключ в браузере;
- проверка подключения к платформе через `GET /v1/me`;
- простой экран будущего BI-дашборда;
- заготовки под список отчётов, визуализацию и AI-команды.
- Gateway-авторизация для встройки: сессия пользователя остаётся между Gateway и сервером;
- локальный режим через личный `vibe_api_...`, чтобы проверять экран до деплоя.
- версии отчёта сохраняются в `.data/dashboard-state.json` локально и в `/data/living-bi-dashboard/dashboard-state.json` в Galaxy-приложении.

## Важное ограничение MVP

Это отдельный дашборд приложения на данных того же портала. Он не читает и не редактирует нативные BI-отчёты Битрикс24: для этого нет доступного REST API. Готовый сценарий демонстрации находится в [docs/demo-script.md](docs/demo-script.md).

## Как работает встройка

В продакшене приложение открывается через `https://vibecode.bitrix24.tech/v1/bitrix-handler`. Gateway определяет пользователя в Битрикс24 и отправляет запрос на сервер с `X-Vibe-Authorization`. Сервер передаёт эту сессию в Vibe API как `Authorization: Bearer`, добавляя ключ приложения из `VIBE_APP_KEY`. Токен не попадает в JavaScript страницы.

Для запуска на Black Hole нужны Node 20, `npm ci --omit=dev`, команда старта `npm run start`, порт `3000` и переменная окружения `VIBE_APP_KEY`. Файл `.env` и `node_modules` в архив деплоя не включаются.

Переменная `DASHBOARD_STATE_PATH` позволяет явно указать путь к постоянному файлу истории. В Galaxy используется выделенный том `/data`, поэтому история не находится внутри директории развёртываемого кода.

## Тестовый деплой

Тестовый экземпляр развёрнут по адресу `https://app-daffcac4becb.vibecode.bitrix24.tech`. Открывать его нужно через пункт «AI-редактор BI-отчётов» в левом меню тестового портала: прямой запрос к URL намеренно требует Gateway-сессию.
