# Точка продолжения разработки

**Дата фиксации:** 10.08.2026
**Ветка:** `main`
**Репозиторий:** https://github.com/igorrosliakov-bitrix24/living-bi-dashboard

## Что подтверждено

- Приложение опубликовано на Galaxy: `https://app-daffcac4becb.vibecode.bitrix24.tech`.
- Пункт «AI-редактор BI-отчётов» открывается в тестовом портале через Gateway.
- Дашборд получает только агрегаты сделок, компаний, задач и активностей. Карточки CRM и персональные данные в виджеты и контекст ИИ не передаются.
- Есть 5-минутный кэш агрегатов и кнопка «Обновить показатели» для явного свежего запроса.
- Поддерживаются KPI, bar, line, pie, donut и table; bar умеет вертикальное и горизонтальное представление, есть палитра Bitrix24.
- Версии сохраняются в постоянный файл Galaxy. Переход к прошлой версии выбирает уже сохранённый снимок, поэтому история не разрастается от отката.
- `npm run seed` создаёт малый набор данных с префиксом `VIBECODE_DEMO_BI`; `npm run seed:load -- --deals=2000 --confirm` создаёт отдельный нагрузочный набор `VIBECODE_LOAD_BI` и защищён от повторного запуска.
- Вычисляемый KPI допускает только выражение `kpi-id / kpi-id` с форматами `number` и `percent`; код в формулах не исполняется.
- Локальные проверки перед следующим деплоем: 41 тест, покрытие строк 88.01%.

## Следующий обязательный прогон

1. Задеплоить текущую ветку в Galaxy.
2. Открыть приложение через placement Битрикс24.
3. Выполнить фразу из сценария 2 в [demo-script.md](demo-script.md): команда → preview → diff → применение.
4. Переключиться на предыдущую версию и убедиться, что число версий не меняется.
5. По желанию создать 1–2 тыс. тестовых сделок через `seed:load` и замерить первый и кэшированный рендер.

## Открытые пункты PRD

4. Согласовать точную продуктовую формулировку приватности BitrixGPT перед публикацией статьи.

## Важные ограничения для статьи

- Приложение не читает и не редактирует нативные BI-отчёты: доступного REST API для этого нет.
- Это отдельный дашборд на данных того же портала, расположенный рядом с BI-конструктором.
- Корректная формулировка: данные не передаются сторонним LLM-провайдерам; обработка идёт в инфраструктуре Битрикс24 и Вайбкода.
