# Материалы к статьям о BI и ИИ

В этой папке собраны исходные материалы и рабочие инструкции для серии статей.

- `article-1-habr.pdf` — опубликованная первая статья в исходном PDF.
- `article-1-prd.md` — PRD первой статьи в исходном виде.
- `article-2-dataset-api-brief.md` — исходное задание на вторую статью про API датасетов.
- `article-2-validation-scenario.md` — сценарий, по которому подтверждаем работу второй версии продукта в живом портале.

Исходники первой статьи и PRD сохранены копиями без изменений. Остальные два файла можно дополнять по мере подготовки статьи.
