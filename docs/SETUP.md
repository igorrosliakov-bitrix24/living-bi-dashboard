# Настройка своего портала

Этот документ описывает техническую настройку копии проекта. Он рассчитан на администратора портала Битрикс24 с доступом к Вайбкод-платформе.

## 1. Создайте приложение и ключи

1. Создайте OAuth-приложение Вайбкода для своего портала.
2. Выдайте приложению права `crm`, `task`, `tasks`, `user`, `placement`, `vibe:ai` и `vibe:infra`.
3. Сохраните ключ приложения `vibe_app_...`: он нужен только серверу.
4. Для локальной разработки создайте отдельный личный ключ `vibe_api_...`.

Не добавляйте ключи в Git, браузер или скриншоты.

## 2. Локально запустите проект

```bash
cp .env.example .env
# Внесите значения VIBECODE_API_KEY и VIBE_APP_KEY.
npm ci
npm run check
npm run dev
```

Откройте `http://127.0.0.1:5174`. Локальный режим использует только `VIBECODE_API_KEY`; данные берутся из вашего портала по правам этого ключа.

## 3. Подготовьте демо-данные

После добавления seed-скрипта выполните `npm run seed`. Скрипт создаёт отдельные тестовые компании, сделки и задачи с префиксом `VIBECODE_DEMO`. Он не изменяет существующие сущности.

Для нагрузочной проверки используйте отдельный префикс и явное подтверждение: `npm run seed:load -- --deals=2000 --confirm`. Скрипт остановится при повторном запуске, чтобы не создавать дубликаты.

## 4. Разверните Galaxy-приложение

В VibeCode создайте Galaxy-сервер с Node 20 и загрузите архив репозитория без `.env`, `.git`, `node_modules`, `.data` и `coverage`.

Используйте настройки:

```text
install: cd /opt/app && npm ci --omit=dev
start: cd /opt/app && npm run start
port: 3000
NODE_ENV: production
VIBE_APP_KEY: vibe_app_...
DASHBOARD_STATE_PATH: /data/living-bi-dashboard/dashboard-state.json
```

После запуска скопируйте Galaxy URL, например `https://app-xxxx.vibecode.bitrix24.tech`.

## 5. Свяжите приложение с меню Битрикс24

1. В объекте OAuth-приложения укажите Galaxy URL как `appUrl`.
2. Привяжите placement `LEFT_MENU` с подписью «AI-редактор BI-отчётов».
3. Вайбкод заменит технический адрес на `https://vibecode.bitrix24.tech/v1/bitrix-handler`.
4. Откройте добавленный пункт из меню портала и нажмите «Обновить диагностику».

Успех: приложение показывает «Подключено», свой портал и доступность AI Router. Прямое открытие Galaxy URL должно требовать Gateway-сессию.
